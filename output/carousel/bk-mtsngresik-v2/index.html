The Problem Context & Constraints

Paper Friction & The Limits of Punitive Discipline

Managing guidance counseling for thousands of students with physical paperwork created compounding administrative bottlenecks.

01

The Physical Binder Trap

Student counseling logs and infraction records lived scattered across physical binders. Identifying multi-year behavioral patterns across grades 7, 8, and 9 took hours of manual record searches.

02

180-Question Tabulation Bottleneck

The standard psychological assessment (Angket Kebutuhan Peserta Didik) required manually distributing, collecting, and calculating 180 questions per student on paper sheets.

03

End-of-Term Reporting Scramble

Compiling semester discipline report cards for hundreds of students across dozens of classes overwhelmed homeroom teachers with manual data entry and transcription errors.

CORE SHIFT: PUNITIVE RETRIBUTION  ➔  POSITIVE DISCIPLINE & PROACTIVE TRIAGE

System Architecture Full-Stack Monolith

Single Monolith, Modern Developer Ergonomics

Combining Laravel 12's backend power with Inertia React 19's SPA responsiveness without REST API overhead.

01. Access & Identity
Students via NISN • Teachers via Google OAuth SSO • Counselors & Admins via 2FA
02. Modern Bridge
Inertia.js v2 + React 19 + TypeScript + Tailwind CSS v4 + Radix UI
03. Core Engine
Laravel 12 (PHP 8.4) • Larastan Level 8 Static Analysis • Pest v4 Feature Tests
04. Data & Export
Academic Year Scoped Tables • Recharts Visualizations • Bulk Merged PDF Synthesis

KEY ARCHITECTURAL DECISION:

By choosing Inertia.js v2 over a decoupled frontend/backend, controllers pass typed Eloquent models directly to React components. Zero API endpoints, zero schema drift, maximum delivery velocity.

Lessons Learned Production Insights

Production Takeaways from Building School Systems

Three foundational principles discovered while taking this platform to production.

01

Scope by Academic Year Early

Treating academic_year_id as a first-class tenant on every transactional model made semester resets and historical student archiving effortless.

02

Inertia.js v2 Velocity

Full-stack type safety with Wayfinder and Larastan allowed rapid feature shipping without the overhead of maintaining and synchronizing a decoupled API layer.

03

Positive Behavioral UX

Gamified, color-coded status badges shifted student and teacher mindsets from avoiding punishment to actively logging positive achievement commendations.
