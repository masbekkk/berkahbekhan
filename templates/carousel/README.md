# Short portfolio carousel

Use one verified project and a focused sequence: introduce the work, show a relevant detail, explain a useful workflow, then invite a conversation. Do not pad to nine slides.

The implemented example is [BK MTsN Gresik](https://www.figma.com/design/rlngsFaoNqCPP8PzeItbLk/Untitled?node-id=51-106). Each slide is 1080 x 1350 with 80px margins.
