# BerkahEmas vertical frame

`frame.svg` is a reusable editable 1080×1920 composition and `frame.png` is its preview export.
It embeds a real rebranded POS screenshot with fictional data; it is a static template, not a finished video.
Replace the embedded `<image>` with the real shot for each beat. Preserve `preserveAspectRatio="xMidYMid meet"`.

- Emerald frame and CTA, ivory caption areas, gold divider.
- Persistent product name and Software Toko Emas descriptor above the proof.
- Hook at 80px left / 310px baseline. Keep it to two short lines.
- Product zone: x72 / y455 / 936×955; fit the real capture without stretching.
- CTA zone: x72 / y1550 / 936×210; keep text and important details away from the bottom edge.
- Use Manrope; source fonts are in `brand/berkahemas/`.
- For phone readability, edit a tighter uniform crop around the actual control/result when full-screen text is too small.

Timed captions, cuts, focus zooms, narration and authenticated recording need an editor/capture setup.
The current baseline compositor does not produce this template automatically.
