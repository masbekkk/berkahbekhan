# Short-form sales video templates

These are persuasion/story structures for recordings of real software. They are not fixed visual templates.

## 1. Result first -> prove it

`WOW RESULT -> buyer relevance -> real steps -> result again -> CTA`

Best default for TikTok/Reels.

Example:

`Booking baru muncul di dashboard -> "customer bisa pilih jadwal sendiri" -> customer flow -> submit -> admin sees booking -> DM CTA`

## 2. Friction -> real workflow

`COMMON BUSINESS FRICTION -> real product action -> visible resolved state -> CTA`

Use general scenario wording unless the project's specific client problem is documented.

## 3. Customer POV -> admin payoff

`CUSTOMER ACTION -> system response -> admin dashboard/result -> business-value overlay -> CTA`

Excellent for booking, order, registration, quote request, or ticket systems because it proves both sides of the workflow.

## 4. One satisfying feature

`HOOK ON ACTION -> 2-3 quick interactions -> instant visible payoff -> CTA`

Best for filters, search, status changes, exports, builders, uploads, calculators, configuration flows.

## 5. Before/after workflow

`GENERAL/VERIFIED BEFORE -> REAL SYSTEM FLOW -> AFTER STATE -> CTA`

Do not fake a client before-state or business outcome.

## 6. Build proof -> business proof

`short implementation credibility -> real UI behavior -> why buyer cares -> CTA`

Use sparingly when engineering depth increases trust.
