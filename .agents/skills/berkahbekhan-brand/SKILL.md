# BerkahBekhan Brand Identity Skill

Use this skill whenever generating, designing, styling, or evaluating content for **berkahbekhan.inc**. This skill provides the definitive visual system, design tokens, layout geometry, and brand principles.

---

## 1. Brand Identity & Positioning

- **Brand**: `berkahbekhan.inc` (Handle: `@berkahbekhan.inc`)
- **Positioning**: Modern developer, software builder, and technical educator.
- **Core Focus**: Real software projects, real architecture, system building, technical problem-solving, and actionable developer knowledge.
- **Visual Personality**:
  - Modern, minimal, technical, clean
  - Confident, professional, human, understated
  - Pragmatic and developer-oriented
  - Zero decorative fluff; high engineering credibility

## 2. Design System Tokens

### Exact Color Palette
Never introduce secondary colors or random gradients without explicit instruction.

| Token | Hex Value | Role |
| :--- | :--- | :--- |
| **Background** | `#0B0F14` | Primary deep dark canvas background for all formats. |
| **Surface** | `#151B23` | Card backgrounds, snippet containers, callout boxes. |

## 3. Typography & Hierarchy

- **Font Pairings**:
  - Primary Sans: **Inter** or **Geist Sans** (Clean, neutral geometric sans).
  - Technical Mono: **JetBrains Mono** or **Geist Mono** (Code, metadata, filepaths, tags).
- **Scale (Feed / Carousel 1080 × 1350)**:
  - Eyebrow Tag: `24px - 28px` Mono (Uppercase, `#60A5FA`).
  - Slide Title: `64px - 76px` Sans (Bold, `#F8FAFC`, line-height `1.15`).
  - Subtitle / Section: `34px - 44px` Sans (SemiBold, `#F8FAFC` or `#60A5FA`).
  - Body Copy: `26px - 30px` Sans (Regular, `#94A3B8`, line-height `1.45`).
  - Code Snippet: `22px - 26px` Mono (`#F8FAFC`, line-height `1.5`).
  - Slide Counter / Footers: `20px - 24px` Mono (`#94A3B8`).

---

## 4. Layout, Spacing & Container Rules

### Canvas Dimensions & Margins
- **Feed / Carousel**: `1080 × 1350 px` (4:5). Margin: `80px` padding on all edges.
- **Story / Reel Cover**: `1080 × 1920 px` (9:16). Top safe margin: `250px`. Bottom safe margin: `350px`. Center safe crop for grid: `1080 × 1080 px`.

### Containers & Cards
- Base surface: `#151B23`.
- Border: `1px solid #263241`.
- Border radius: `16px` or `20px` for cards; `8px` for inner pills/code blocks.
- Spacing rhythm: 8px scale (`8px`, `16px`, `24px`, `32px`, `48px`, `64px`).

### Screenshot & Asset Treatment
- **Screenshot Dominance**: The real application screenshot or genuine UI must remain the primary visual element. Never shrink screenshots to make space for decorative illustrations.
- **Orthographic Framing**: Screenshots must be presented flat and clean. No 3D tilting, isometric angles, or fake phone hand mockups.
- **Window Frame**: Subtle dark window bar (`#151B23`) with optional 3 neutral dots, enclosed in `1px solid #263241` with `12px - 16px` rounded corners.

### Header & Footer Treatment
- **Header**: Top left displays topic badge (e.g. `[ CASE STUDY ]` or `[ ARCHITECTURE ]`) in JetBrains Mono.
- **Footer**:
  - Left: `@berkahbekhan.inc` (Muted `#94A3B8`).
  - Right: Page index (e.g., `01 / 07`, `04 / 06`) in JetBrains Mono.

---

## 5. Visual Consistency Enforcements

1. **Avoid Excessive Visual Decoration**: No floating 3D geometric shapes, neon halos, rainbow gradients, or glassmorphism blur layers.
2. **High Information Density with Generous Whitespace**: Keep text blocks tight and purposeful; let negative space frame the screenshots.
3. **Always Refer to Canonical Brand Docs**:
   - `brand/colors.md`
   - `brand/typography.md`
   - `brand/visual-rules.md`
   - `brand/content-rules.md`
